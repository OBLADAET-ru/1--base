## 📖 О проекте

**1С База Знаний** — это открытый учебник по разработке на платформе **1С:Предприятие 8.3+**, организованный по принципу классического учебника. Материал разбит на 16 параграфов, объединённых в 5 частей.

Каждый параграф содержит:
- 📚 теоретическую часть с пояснениями
- 💻 практические примеры кода с подсветкой синтаксиса
- 💡 советы, предупреждения и важные замечания
- 📊 таблицы с операциями, событиями, свойствами

## 🛠 Технологии

Проект полностью реализован **в одном файле `index.html`** — без зависимостей, сборщиков и backend:

| Технология | Назначение |
|------------|-----------|
| **HTML5** | Разметка страниц и параграфов |
| **CSS3** | Тёмная тема, адаптивность, анимации |
| **Vanilla JavaScript** | Роутинг по параграфам, поиск, копирование |

**Никаких:**
- ❌ npm / node_modules
- ❌ React / Vue / Angular
- ❌ Webpack / Vite
- ❌ Препроцессоров

**Разверните сайт:** просто скопируйте `index.html` на любой хостинг.
